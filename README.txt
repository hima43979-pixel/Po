نسخة تصميم YOKA الأصلي بعد الإصلاح ❤️

المحتويات:
- index.html: نفس تصميم شاشة القفل، التحميل، الصفحة الرئيسية، الرسالة السرية.
- assets/yoka-1.jpg إلى yoka-4.jpg: صور YOKA التي أرسلتها.
- assets/yoka-song.mp3: الأغنية التي أرسلتها.

لرفعها إلى GitHub Pages:
1. فك ضغط ZIP.
2. ارفع index.html ومجلد assets (بمحتوياته) إلى جذر المستودع.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. انتظر نشر الموقع ثم افتح رابط Pages.

مهم: زر اختيار أغنية/صور من الجهاز يعمل محليًا فقط على نفس الجهاز؛ الملفات المضمنة في assets هي التي تظهر لكل من يفتح الرابط.
المتصفح قد يمنع التشغيل التلقائي للصوت؛ اضغط زر الموسيقى بعد فتح الموقع.
